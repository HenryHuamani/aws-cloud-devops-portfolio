# 👨‍💻 About This Portfolio

This repository is a hands-on Cloud, Infrastructure and DevOps engineering portfolio focused on designing, deploying, securing, operating, and monitoring infrastructure using **Amazon Web Services (AWS)** and modern infrastructure engineering practices.

The portfolio currently demonstrates practical experience across:

- AWS cloud infrastructure
- Identity and access management
- Amazon EC2 and Linux administration
- Amazon S3 object storage
- VPC networking and security
- Application Load Balancing
- Auto Scaling and automatic recovery
- Amazon RDS relational databases
- Amazon EFS shared storage
- Amazon CloudWatch monitoring and alerting
- High availability and scalability
- Infrastructure troubleshooting
- Architecture documentation
- Operational validation

Each laboratory contains technical documentation and, where applicable, architecture diagrams, implementation commands, scripts, troubleshooting notes, interview preparation material, and implementation evidence.

The next stage of the portfolio focuses on expanding the current AWS infrastructure into an automated Cloud and DevOps platform using:

- IAM Roles and advanced access control
- AWS CloudTrail
- Docker
- GitHub Actions
- Kubernetes
- DevSecOps practices
- Prometheus and Grafana
- Site Reliability Engineering practices
- Production-oriented architecture patterns

The long-term objective is to evolve the existing laboratories into integrated, production-oriented Cloud and DevOps projects demonstrating practical capabilities relevant to roles such as:

**Cloud Engineer • DevOps Engineer • Infrastructure Engineer • Site Reliability Engineer (SRE) • Platform Engineer • Solutions Architect**
